# Global Shark Attack Data Analysis

An exploratory data analysis project investigating global shark attack records using Python, pandas and Matplotlib. The project focuses on data cleaning, identifying patterns, visualising trends and interpreting findings.

## Research questions
- How do recorded fatality proportions compare for surfing and other activities?
- How do recorded provoked incidents differ by reported sex?
- How do attack counts and fatality proportions vary by identified shark species?

## Tools
Python, pandas, matplotlib, Jupyter Notebook.

## Running the notebook
1. Install dependencies with `pip install -r requirements.txt`.
2. Obtain an appropriately licensed copy of the dataset and place it at `data/shark-attacks-cleaned.csv`.
3. Open `shark_attack_data_analysis.ipynb` from the repository root.

## Limitations
The findings describe *recorded incidents*, not population-adjusted attack risk. Reporting bias, missing records, inconsistent labels and uncertain species identification can affect conclusions.
